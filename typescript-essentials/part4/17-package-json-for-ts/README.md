# Chapter 17 — `package.json` for TS Readers

## Files

- `app-package.json` — minimal application package.json with `type: module`.
- `library-package.json` — modern library with `exports`, conditions, `attw`-friendly setup.
- `subpath-imports.json` — `package.json#imports` for path aliases without a build step.

These are reference files; copy into a real project as `package.json`.
