# Chapter 10 — Narrowing Primitives

The five built-in narrowing forms: `typeof`, `instanceof`, `in`, equality, truthiness.

## Files

- `narrowing-primitives.ts` — one example per primitive.
- `truthiness-pitfall.ts` — the empty-string and zero-falsy footguns.
- `event-discriminator.ts` — discriminator-field narrowing tying it all together.

npx tsx part3/10-narrowing-primitives/narrowing-primitives.ts
npx tsx part3/10-narrowing-primitives/event-discriminator.ts
