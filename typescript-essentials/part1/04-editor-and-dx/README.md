# Chapter 4 — Editor + DX

Most of this chapter is about workflow rather than code. The two artifacts worth shipping with the repo:

## Files

- `vscode-settings.json` — the recommended VS Code settings JSON from the chapter (workspace TS version, format-on-save, inlay hints).
- `inlay-hints-demo.ts` — a small file you can hover over to see how the language server reports inferred types.

To use the settings: copy `vscode-settings.json` to `.vscode/settings.json` in your project root.
