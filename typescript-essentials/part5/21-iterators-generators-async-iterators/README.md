# Chapter 21 — Iterators, Generators, Async Iterators

## Files

- `range-generator.ts` — a custom iterable via generator function.
- `take-generator.ts` — generic `take<T>` over any iterable.
- `paginated-fetcher.ts` — async generator pulling pages from an API.
- `read-lines.ts` — reading a file line-by-line via async iteration.

## Run

```bash
npx tsx part5/21-iterators-generators-async-iterators/range-generator.ts
npx tsx part5/21-iterators-generators-async-iterators/take-generator.ts
npx tsx part5/21-iterators-generators-async-iterators/paginated-fetcher.ts
npx tsx part5/21-iterators-generators-async-iterators/read-lines.ts
```
