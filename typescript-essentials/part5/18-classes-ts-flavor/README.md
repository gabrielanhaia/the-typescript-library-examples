# Chapter 18 — Classes, TS Flavor

## Files

- `parameter-properties.ts` — the constructor-shorthand for class fields.
- `private-fields.ts` — TS `private` modifier vs JS-native `#field`.
- `abstract-class.ts` — abstract class hierarchy (and the discriminated-union alternative).
- `override-keyword.ts` — `override` and what `noImplicitOverride` catches.
- `custom-error.ts` — `class extends Error` with `instanceof` narrowing in catch.
